# Portfolio Website - Muhammad Radifan Asyauri

A modern, soft neo-brutalist portfolio website built for **Muhammad Radifan Asyauri**, Data Science Student & Automation Engineer.

Live Preview / Deployable on **Vercel**.

---

## 🛠 Tech Stack

- **Framework**: React 19 + TypeScript (`.tsx`)
- **Bundler**: Vite
- **Styling**: Tailwind CSS (Custom Soft Neo-Brutalism Design Tokens)
- **Icons**: Lucide React + Inline SVGs
- **Deployment**: Vercel ready (`vercel.json`)

---

## 🚀 Features

- **Soft Neo-Brutalism Aesthetics**: High-contrast, tactile mechanical buttons, hard offset box-shadows, and eye-friendly calm color palette (Honey Butter, Sage Green, Coastal Slate, Terracotta).
- **Responsive & Accessible**: WCAG AA color contrast compliant, full keyboard accessibility, zero mobile overflow.
- **Dual Themes**: Complete Light Mode & Dark Mode with automatic preference detection and `localStorage` persistence.
- **Authentic Engineering Showcase**:
  - **SuperFood Multi-City Merchant & Review Scraper** (Playwright, Python, cookie auto-refresher, Excel automation).
  - **Surabaya City Portal & Interactive Demographic Map** (Diskominfo Surabaya, Web GIS, statistical dashboard, PPID complaint portal).
  - **CVMatch AI** (Semantic similarity resume analyzer & job recommender).
  - **RAG Document Intelligence** (LangChain, vector store).
- **Interactive Modals**: Case study detail drawers with key implementation highlights.
- **Contact Station**: Validated dispatch form with instant email copy action.

## 💻 Local Development

1. **Install dependencies**:
   ```bash
   npm install
   ```

2. **Run local dev server**:
   ```bash
   npm run dev
   ```

3. **Build for production**:
   ```bash
   npm run build
   ```

4. **Preview production build**:
   ```bash
   npm run preview
   ```

---

## 📦 Deployment to Vercel

### Option 1: Using Vercel CLI
```bash
npm i -g vercel
vercel
```

### Option 2: Git Integration
Connect this repository directly to [Vercel Dashboard](https://vercel.com/new). The Vite preset is automatically configured.
